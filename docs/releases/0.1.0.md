# Minecraft Agent Tools 0.1.0

The first experimental release connects an MCP client to a Forge 1.7.10 world
through five removable tool providers: Minecraft, NEI, GregTech, Schematica and
BetterQuesting. The MCP HTTP endpoint runs inside the game's Java 8 JVM; the
external Java 21 stdio launcher is optional.

## Downloads

Start with **minecraft-agent-tools-0.1.0-bundle.zip**. Its directories explain
where each component belongs:

| Directory | Install into | Purpose |
| --- | --- | --- |
| `forge/` | Minecraft `mods/` | MCP host and base Minecraft adapter |
| `plugins/` | `config/minecraftagenttools/plugins/` | Choose the tool providers you need |
| `client-mods/` | Client `mods/` | NEI, Schematica and BetterQuesting adapters |
| `gregtech-mods/` | Server/integrated-server `mods/` | GregTech adapter |
| `harness-mods/` | Client `mods/`, with Harness 0.1.0 | Optional schematic and quest widgets |

Install the required upstream mods separately. Each adapter requires the matching
mod on the same side. **Do not install every release JAR into `mods/`.**
`mcp-api`, `bridge-protocol`, `game-bridge`, `-dev` and `-sources` JARs are for
addon developers; the bundle contains the deployable files.

See the [installation guide](https://github.com/sorivma/minecraft-agent-tools/blob/v0.1.0/docs/getting-started.md)
and [embedded MCP setup](https://github.com/sorivma/minecraft-agent-tools/blob/v0.1.0/docs/embedded-mcp.md).

## Verification and compatibility

The release workflow runs standalone builds on Linux and Windows, isolated
unit/integration tests, formatting checks, Java 8 bytecode/module-boundary checks,
and both Harness widget integrations before publishing. `SHA256SUMS` covers every
asset; public release binaries include GitHub build attestations.

This is an experimental `0.x` release. In-game validation remains partial; CI does
not certify arbitrary Forge/GTNH modpack combinations. The MCP profile uses JSON
responses and does not provide every optional MCP capability. Players perform
movement, crafting and real block placement themselves.

Tokens grant broad observation access. Keep the local HTTP endpoint and bridge
credentials private. See [Security](https://github.com/sorivma/minecraft-agent-tools/blob/v0.1.0/SECURITY.md).
