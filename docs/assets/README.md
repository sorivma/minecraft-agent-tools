# README artwork

`cover.png` is an original AI-generated concept illustration created with the
built-in image generation tool. It illustrates observation and blueprint planning;
it is not a screenshot or evidence of an in-game result. Both README languages use
the same local asset. No external image host is required.

## Generation prompt

```text
Use case: stylized-concept
Asset type: wide GitHub repository README cover illustration for an independent project named Minecraft Agent Tools.
Primary request: a polished editorial voxel illustration communicating an AI agent observing a Minecraft-like block world and planning ghost structures.
Scene: a small floating cutaway voxel terrain island with grass, stone layers, one oak tree, a tiny workshop with chest and industrial machinery, and a partially completed cyan wireframe building blueprint hovering over the terrain. Three elegant thin circuit paths extend leftward to a small abstract geometric agent node.
Style: meticulous isometric 3D voxel art, architectural model quality, beautiful restrained materials and ambient occlusion, not a screenshot, not a UI mockup.
Composition: ultra-wide banner, about 3:1 landscape, entire scene comfortably within the frame, generous dark negative space, clear silhouette at README thumbnail size.
Lighting: warm amber workshop light contrasting with cool cyan blueprint glow, very dark graphite blue background, tasteful and understated.
Constraints: original illustration, no copied game textures, no characters, no official logos, no watermark, no text, no letters, no fake performance metrics, no floating interface panels. Keep geometry crisp and coherent.
```

`architecture.svg` is a repository-authored vector diagram of the actual process
and thread boundaries. Keep its labels in sync with `docs/architecture.md`.
