# Minecraft Agent Tools

- Это самостоятельный проект, соседний с `minecraft-harness`; не добавлять зависимость от Harness.
- `bridge-protocol` совместим с Java 8 и не зависит от Minecraft или MCP SDK.
- `mcp-server` работает отдельным процессом на Java 21; `forge-1.7.10` — адаптер Java 8.
- Ядро MCP не содержит встроенных инструментов: провайдеры загружаются из `plugins/*.jar`
  при старте через `mcp-api`. Отсутствующий JAR не должен регистрировать свои инструменты.
- Minecraft-контракт и провайдер находятся в `minecraft-tools`; Forge включает только Java 8
  контракт, без реализации MCP-провайдера, Java 21 или современного Gson.
- Обращения к Minecraft выполнять на игровом потоке, сетевой ввод-вывод — вне него.
- Привязывать команды и метки к миру/сессии и измерению; не применять устаревшие команды после смены мира.
- Не интерпретировать текст карточек чата как команды изменения мира.
- Можно выполнять сборку, статический анализ и изолированные тесты. Игру, живой MCP/backend
  и runtime-проверки запускает пользователь, если он отдельно не поручил их агенту.
- Не объявлять каркас рабочим MCP-сервером: до реализации инструментов это только структура проекта.
